Creative Coding Sketches

Eleven short p5.js sketches, in the order of the lesson. Open one, then edit its sketch.js in VS Code and save. Live Server reloads the page for you.

  1. Fundamentals · 1 Variables and conditionals A variable holds a value. A conditional picks one of two branches every frame. sketches/01-variables-and-conditionals/sketch.js
  2. Fundamentals · 2 Loops A loop repeats a step. A nested loop visits every cell of a grid. sketches/02-loops/sketch.js
  3. Fundamentals · 3 Functions A function names a step so you can reuse it. A function can also return a value. sketches/03-functions/sketch.js
  4. Fundamentals · 4 Objects A class bundles data with the behaviour that changes it. Each object updates once per frame. sketches/04-objects/sketch.js
  5. Algorithms · 5 Nearest point search A linear search checks every point and keeps the best so far. sketches/05-nearest-point-search/sketch.js
  6. Algorithms · 6 Mapping and easing map() rescales a value between ranges. lerp() moves a fraction of the way towards a target. sketches/06-mapping-and-easing/sketch.js
  7. Media · 7 Pixels as an array An image is a flat list of numbers, four per pixel: red, green, blue and alpha. sketches/07-pixels-as-an-array/sketch.js
  8. Media · 8 Vectors and transforms A vector has a direction and a length. Transforms move and turn the drawing space. sketches/08-vectors-and-transforms/sketch.js
  9. Media · 9 3D with WEBGL WEBGL adds a third axis and a camera. The same loop draws the scene each frame. sketches/09-3d-with-webgl/sketch.js
  10. Data and signals · 10 A signal over time A signal is a stream of samples. Keep a history, draw it, and smooth it with a filter. sketches/10-a-signal-over-time/sketch.js
  11. Systems · 11 Particle system Many simple objects, each updated by forces every frame, can produce complex behaviour. sketches/11-particle-system/sketch.js
Sketches use p5.js 1.9.4, loaded from cdnjs (needs an internet connection). Move the mouse over the canvas; the sketches respond to it.
